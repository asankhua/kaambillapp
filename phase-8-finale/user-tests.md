# Real-user tests (Phase 8 §1.4): 5–10 tradespeople

## Consent (read aloud, in Hindi/Hinglish)

"Hum ek bill banane wala app test kar rahe hain. Aap ek asli kaam ka bill bolkar banayenge. Hum time aur aapki baatein note karenge; video sirf aapki ijazat se, aur sirf is project ke liye. Aap kabhi bhi rok sakte hain." → note **yes / no** for notes, audio, video.

## Setup

- Their own phone if possible (install from the Vercel URL), else ours. Onboard with **their** business name; UPI ID can be ours for the test.
- No coaching beyond: "Mic dabaiye aur aaj ke kisi kaam ka bill boliye."

## Tasks

1. Make a bill for a real job they did today (any items).
2. Fix one quantity (by voice or by tapping).
3. Send it to our test WhatsApp number.
