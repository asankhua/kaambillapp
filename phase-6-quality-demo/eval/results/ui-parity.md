# UI parity: built screens vs Stitch designs (21 Nov, after the Stitch rebuild)

Side-by-side images (Stitch left, build right, 390 px wide like the Stitch export) are in [`ui-parity/`](./ui-parity/); raw build screenshots in `ui-parity/build/`. Regenerate with **`npm run ui:parity`** (Playwright drives every screen with mocked data). In the captures the fixed top bar and dock are drawn in page flow, so there is some empty padding under the header and above the dock that isn't visible on a phone.

## History

- **14:05**: first parity check (pre-restructure build).
- **16:30**: found the app had shipped **unstyled** since the phase-folder move (Tailwind `@source` glob matched nothing). Fixed; an e2e test now checks computed theme colours.
- **16:45**: honest re-check of the styled build: every screen was a simplified version of Stitch.
- **17:30**: all screens rebuilt from each screen's Stitch `code.html` (this report). Also: text-to-speech removed (user decision), icon sizes fixed (Google's icon CSS forced every icon to 24 px).
